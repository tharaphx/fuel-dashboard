Route ID ↕ ยอดขายลิตร (เทียบปีก่อน / เป้า) ↕ น้ำมันขาด/เกิน (%) ↕ กำไรขั้นต้นรวม ↕ ต้นทุน + กำไรขั้นต้น ต่อลิตร ↕ ค่าซ่อม ↕ อัตราการใช้น้ำมัน (เทียบเป้า) ↕ เงินสด : เงินเชื่อ (เทียบเป้า) ↕
แถวคือ 1 Route ID · ชื่อรถใต้ Route ID = รถที่วิ่งเส้นทางนี้ในเดือนที่เลือก (สลับรถได้ตามจริง) · แถวที่มีแถบสีแดงด้านซ้าย = เส้นทางนี้ติดอยู่ในรายการเฝ้าระวัง (Zone 2) อย่างน้อย 1 ข้อ · แถว "ไม่มี Route ID" = ยังไม่ได้กรอก Route ID ในชีตต้นทาง ระบบใช้ชื่อรถแทนไปก่อน
