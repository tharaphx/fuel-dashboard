# Fuel Ops Dashboard

Interactive dashboard เดี่ยวไฟล์เดียว (`index.html`) เชื่อมข้อมูลสดจาก Google Sheet ที่ให้มา ไม่ต้อง build ใดๆ

## วิธีนำไปใช้บน GitHub Pages

1. สร้าง repository ใหม่บน GitHub (public หรือ private ก็ได้ ถ้าจะใช้ GitHub Pages ฟรีต้องเป็น public หรือมี GitHub Pro สำหรับ private)
2. อัปโหลดไฟล์ `index.html` ไว้ที่ root ของ repo
3. ไปที่ Settings → Pages → เลือก branch (เช่น `main`) และ folder `/ (root)` แล้วกด Save
4. รอสักครู่ จะได้ลิงก์ประมาณ `https://<username>.github.io/<repo>/`

## ข้อกำหนดของ Google Sheet

- ต้องตั้งค่าการแชร์เป็น **"ทุกคนที่มีลิงก์ – ผู้ดู (Viewer)"** ไม่เช่นนั้น dashboard จะโหลดข้อมูลไม่ได้ เพราะไฟล์นี้ดึงข้อมูลตรงจาก endpoint export ของ Google Sheets แบบไม่ใช้ login
- **แท็บหลัก (ต้องเป็นแท็บแรกของไฟล์)** โครงสร้างคอลัมน์ต้องเรียงตามลำดับนี้:
  `BU, Year-Month, รถ, Route ID, ขายสด (Liter), ขายเชื่อ (Liter), ขายสด (THB), ขายเชื่อ (THB), ต้นทุนขาย (THB), กำไรขั้นต้น, จำนวนเที่ยววิ่ง, ระยะทาง (กม.), เติมน้ำมัน (Liter), น้ำมันขาดเกิน (Liter), อัตราการใช้น้ำมัน, ค่าซ่อม, Target Sales (Liter), Target Fuel Rate (km/L)`
  - คอลัมน์ใหม่ๆ (`Target Sales (Liter)`, `Target Fuel Rate (km/L)`) ถูกต่อท้ายไว้ท้ายแถวเสมอ ไม่แทรกกลาง เพื่อไม่ต้องขยับตำแหน่งคอลัมน์เดิมทุกครั้งที่เพิ่มของใหม่ — ถ้าจะเพิ่มคอลัมน์อีกในอนาคต ให้ต่อท้ายเช่นกัน
  - `Target Fuel Rate (km/L)` คือเป้าหมาย "อัตราการใช้น้ำมันต่อคัน/เส้นทาง" ซึ่ง**แตกต่างกันได้ในแต่ละแถว** ถ้าปล่อยว่าง แถวนั้นจะแสดงเป็น "ไม่มีเป้า"
- คอลัมน์ `Year-Month` ต้องเป็นรูปแบบ `YYYY-MM` เช่น `2026-05` เพื่อให้ dashboard เทียบเดือนเดียวกันของปีก่อนได้ถูกต้อง
- **แท็บ "Targets"** (คอลัมน์: `BU, Target Cash %`) — เก็บเป้าสัดส่วนเงินสดต่อ BU
- **แท็บ "Config"** (คอลัมน์: `Key, Value`) — เก็บค่านโยบายที่ปรับเปลี่ยนได้บ่อยๆ โดยไม่ต้องแก้โค้ด ปัจจุบันมีแถวเดียว: `FuelDiffTolerancePct` = ค่า ± ที่ยอมรับได้ของ "น้ำมันขาด/เกิน (%)" (ค่าเริ่มต้นถ้าไม่กรอกคือ 0.5 หมายถึง ±0.50%)
- **แท็บ "ซ่อมบำรุง"** (คอลัมน์: `BU, Year-Month, รถ, รายการซ่อม, ค่าใช้จ่าย, ศูนย์ซ่อม`) — รายการซ่อมย่อยของ Zone 4 (Route ID ในโซนนี้อ้างอิงข้ามมาจากแท็บหลักโดยจับคู่ BU+Year-Month+รถ)
- ถ้าจะเปลี่ยนไปใช้ Google Sheet คนละไฟล์ ให้แก้ค่า `SHEET_ID` ที่ต้นไฟล์ `index.html` (บรรทัดแรกๆ ใน `<script>`) เป็น ID ของชีตใหม่ (ส่วนที่อยู่ระหว่าง `/d/` กับ `/edit` ใน URL)

## ฟีเจอร์หลัก

- แท็บเมนู "ZONE 1-5" ด้านบนสุด (อยู่แถวเดียวกับแถบตัวกรองด้านล่าง) คลิกเพื่อสลับดูทีละโซน ไม่ต้องเลื่อนจอยาว — ข้อมูลของทุกโซนยังคำนวณอยู่เบื้องหลังตลอด แค่ซ่อนโซนที่ไม่ได้เลือกไว้เฉยๆ
- ตัวเลือก "เดือน-ปี" และ "หน่วยธุรกิจ (BU)" ที่ด้านบน กรองข้อมูลทั้งหน้าแบบเรียลไทม์ พร้อมช่องค้นหา Route ID/รถ (ใช้ร่วมกันทุกโซน ไม่ต้องตั้งค่าใหม่เวลาสลับแท็บ)
- ทุกเดือนที่เลือกจะเทียบกับเดือนเดียวกันของปีก่อนหน้าโดยอัตโนมัติ
- ปุ่ม "รีเฟรช" ดึงข้อมูลใหม่จาก Google Sheet ทันทีโดยไม่ต้อง reload หน้า, ปุ่ม "ธีม" สลับโหมดสว่าง/มืด
- Zone 1: KPI ภาพรวม 5 การ์ด (ยอดขาย, กำไรขั้นต้น, น้ำมันขาด/เกินเทียบเป้า ±ค่าที่ตั้งในแท็บ Config, อัตราการใช้น้ำมันเฉลี่ย, สัดส่วนเงินสด-เงินเชื่อเทียบเป้า)
- Zone 2: กราฟเจาะลึกที่ตารางแทนไม่ได้ (scatter ค่าซ่อม vs อัตราการใช้น้ำมัน, จำนวนเที่ยววิ่งรายเส้นทาง, น้ำมันขาด/เกินรายเส้นทาง, แนวโน้มยอดขาย/กำไร 12 เดือน)
- Zone 3: ตารางประสิทธิภาพรายเส้นทาง (Route ID) 5 คอลัมน์ ออกแบบแบบ "low-noise" — ตัวเลขหลักเป็นตัวหนาสีเข้ม (Primary Metric) ส่วนข้อความรองเป็นตัวเล็กสีเทา/สีความหมาย (Secondary) ไม่มี pill/badge พื้นสีสำหรับค่าปกติ สงวน badge พื้นเข้ม+ไอคอน ⚠️ ไว้เฉพาะกรณีวิกฤตจริงๆ เท่านั้น ได้แก่ Route ID, ยอดขาย & ผลต่างน้ำมัน (ยอดขายลิตรตัวหนา + น้ำมันขาด/เกิน: ข้อความสีเขียว/ส้มสำหรับในเกณฑ์/เฝ้าระวัง, badge แดงเข้ม ⚠️ เฉพาะระดับวิกฤต — พร้อม %YoY และ %เทียบเป้าด้านล่างเป็นข้อความสีความหมาย), ผลประกอบการกำไร (กำไรขั้นต้นรวมตัวหนา + ราคาขาย/ต้นทุน/กำไรต่อลิตร), ค่าซ่อม & ประสิทธิภาพน้ำมัน (ยอดค่าซ่อมตัวหนา, ขึ้น badge แดงเข้ม ⚠️ เฉพาะเมื่อ > ฿10,000 + อัตราสิ้นเปลืองเทียบเป้าเป็นข้อความสีความหมาย), เงินสด:เงินเชื่อ (เทียบเป้า) — แสดงสัดส่วน "% : %" ตัวหนาชิดกลาง พร้อมข้อความเทียบเป้าเล็กสีความหมายด้านล่าง (ไม่มีแท่งกราฟ)
  - เกณฑ์ระดับ "วิกฤต" ของ badge น้ำมันขาด/เกิน คือเกิน 2 เท่าของค่า `FuelDiffTolerancePct` (แท็บ Config) ปรับได้ที่ค่าคงที่ `FUEL_DIFF_CRITICAL_MULTIPLIER` ต้นไฟล์ `index.html`
- Zone 4: รายการซ่อมประจำเดือน พร้อม KPI การ์ด (ยอดรวม, จำนวนรถ, รถที่ค่าซ่อมสูงสุด, จำนวนศูนย์ซ่อม), ช่องค้นหา, ตัวกรองประเภทงาน/ศูนย์ซ่อม, และปุ่มสลับมุมมองตารางปกติ/จัดกลุ่มตามทะเบียนรถ (Accordion)
- Zone 5: จุดที่ควรเฝ้าระวัง (ค่าซ่อมสูงผิดปกติ, กำไร/ลิตรต่ำผิดปกติ, ยอดขายหดตัวจากปีก่อน, น้ำมันขาด/เกินนอกเป้า, อัตราการใช้น้ำมันต่ำกว่ากองรถ)

## ข้อจำกัดที่ควรทราบ

- "ประเภทงาน" ใน Zone 4 (อะไหล่ / ค่าแรง / ยาง) จัดหมวดอัตโนมัติจากคำในชื่อรายการซ่อม (keyword matching) ไม่ใช่ข้อมูลจริงจากชีต — อาจไม่แม่นยำ 100% ถ้าต้องการความแม่นยำเต็มที่ แนะนำเพิ่มคอลัมน์ "ประเภทงาน" ในชีต "ซ่อมบำรุง" โดยตรงแล้วแจ้งได้ จะปรับโค้ดให้อ่านจากคอลัมน์นั้นแทน
- สัดส่วน "เงินสด-เงินเชื่อ" คำนวณจาก **จำนวนลิตร** (ไม่ใช่จำนวนบาท)
- ค่าซ่อมในต้นทางมีเฉพาะยอดรวมต่อคันต่อรายการ (จากแท็บ "ซ่อมบำรุง") ไม่มีวันที่ซ่อมแยกละเอียด
